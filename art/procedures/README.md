# Clinic procedure illustrations

Each of the 18 procedure cards has a distinct 640×360 SVG medical dossier illustration. The illustrations are generated from `scripts/generate_procedure_art.py`; that script also records each asset path in `src/data/medical/procedures.json`. The palette and visual frame match the game's dark olive and brass interface. To regenerate, run `python scripts/generate_procedure_art.py`.
