# Workplace action art

Generated with the built-in image generation tool on 2026-11-21 for Reclaim. Each image depicts a distinct workplace response by one fictional adult woman on the farm. No player character, second person, external reference photo, or named artist style was used. Images were normalized to 720 × 480 WebP.

| File | Action |
| --- | --- |
| `inspect-v2.webp` | Inspect completed work and records |
| `praise-v2.webp` | Praise a worker |
| `punish-v2.webp` | Issue a nonviolent reprimand |
| `threaten-v2.webp` | Threaten disciplinary consequences |
| `day-off-v2.webp` | Excuse a worker from the shift |

The prompts used a mature sensual tone, fitted farm clothing, a grounded cinematic painterly look, warm side light, a 3:2 horizontal composition, and excluded text, logos, nudity, sexual acts, and physical violence.
