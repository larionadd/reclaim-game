# Workplace action art

Generated with the built-in image generation tool on 2026-11-21 for Reclaim. Each image depicts a distinct nonsexual workplace action at a postwar Ukrainian farm. Fictional adult characters; no external reference photos or named artist styles were used. Images were normalized to 720 × 480 WebP.

| File | Action |
| --- | --- |
| `inspect.webp` | Inspect completed work and records |
| `praise.webp` | Praise a worker |
| `punish.webp` | Issue a nonviolent reprimand |
| `threaten.webp` | Threaten disciplinary consequences |
| `day-off.webp` | Excuse a worker from the shift |

The prompts used a grounded cinematic painterly look, warm side light, muted olive and brown palette, a 3:2 horizontal composition, and excluded text, logos, sexual content, and physical violence.
